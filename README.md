# 🔳 QR Code Component

My solution to the [QR Code Component challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) on [Frontend Mentor](https://www.frontendmentor.io) — a classic first challenge for practicing HTML & CSS fundamentals by building a clean, centered QR code card.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Frontend Mentor](https://img.shields.io/badge/Frontend%20Mentor-Challenge-3e54a3?style=for-the-badge)

## ✨ Features

- 🖼️ Centered QR code card component matching the provided design
- 🔤 Google Fonts integration (**Outfit** & **Work Sans**)
- 📱 Responsive, mobile-friendly layout
- ⭐ Custom favicon included

## 🛠️ Tech Stack

- HTML5
- CSS3 (external stylesheet in `css/styles.css`)
- Google Fonts

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/shena9y/front-end-mentor-chalange01.git
   ```
2. Open `index.html` in your browser — no build step required.
